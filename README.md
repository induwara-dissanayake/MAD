# 📱 VillageConnect

VillageConnect is a mobile application developed for the **SE303.3 – Mobile Application Development** module at **NSBM Green University Town (2025/2026)**.

The app digitizes village-level administrative services and improves communication between residents and the **Grama Niladhari (GN)**.

---

## 🎯 Purpose

* Reduce manual paperwork and physical visits to GN offices
* Provide digital certificate requests and status tracking
* Improve village communication through official notices and community posts

---

## 🚀 Key Features

* Digital GN certificate requests
* Official GN notice board
* Lost & Found and community job posts
* Request status tracking
* Help / Chatbot for user guidance (powered by [OpenRouter](https://openrouter.ai); API key and model are set in `lib/core/config/openrouter_secrets.dart`)

---

## 👥 Users

* **Residents** – request services and view community updates
* **GN Officer** – manage requests and publish notices
